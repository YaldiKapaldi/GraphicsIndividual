
(Blender_Project_Files_V1)
I started out with a simple sketch of a body and pumpkin to use as a reference when modeling. With the basic cube, I extruded and loop cut regions to be able to add more detail. I found the mirror modifier was useful here to keep it symetrical and half the work load. Subdiving allowed it to have a smoother look as well as add more details.


(Blender_Project_Files_V2)
Following on from the body model, I added a rig so that I could move it around a lot easier. I found this gave me more freedom moving and animating the body.

(Blender_Project_Files_V3)
I used a different technique for modelling the pumpkin. I started with the cube, subdivided it and used the sculpting tool to draw the face and cut it out. I used other tools to raise the surface to give eyebrows and also added slight dents around the pumpkin to give it a realistic look. I then used the vertex paint option to give it some colour. I used the shading tab to edit the material properties. This allowed the light to reflect on it properly. Finally I added a light source inside the pumpkin to act as a candle which gave it a nice glow.


(Blender_Project_Files_V4)
I used the append feature to add both models together. I deleted the head portion of the body and placed the pumpkin in its place. I joined the objects together and reconfigered the rig to be able to act on the pumpkin as well. I used the vertex paint option to add slight details to the body, giving it a rough look of a scarecrow.


(Blender_Project_Files_V5)
Finally for the render, I posed the body into a position to give the impression of moving. I added a plane for the floor and added a straw texture. I modelled some basic trees using a cube and free forming the branches. I changed the background colour of the scene to black to add a sense of mystery. For the fog, I created a cube and scaled it to the size of the ground. I changed the material so that it used Principled volume instead of the default Principled BSDF. This allowed me to change the density and create a fog effect. I added a few light sources around and moved the camera to a good angle. I changed a few settings on the camera so that it had a focal length of 48mm and the type was Perspective.
